一个聚合了你所有快递和出库码的APP

## 主要功能

- 基于Miuix的现代化UI界面
- 高度优化的软件包体积和缓存管理
- 完善的个性化定制
- 一站式取件码管理和导入
- 聚合两大主流驿站系统身份码，快捷展码出库
- 所有页面均来自官方，保证数据安全

## 工作方式

### 身份码

身份码通过直接对官方取件码页面进行定制并通过WebView显示，未破解任何API接口，软件本身也不负责生成任何条形码/二维码。

在查看过程中，Webview会正常缓存部分静态资源，因此软件会产生一定量的缓存，这些缓存在达到某些阈值后将被自动清理，正常情况下无需手动处理

### 取件码

通过复用已绑定身份码的Cookie，在WebView中打开官方取件码查询页面。利用正则表达式在页面中查找取件码结构(XX-X-XXXX)并自动分类。

匹配和存储操作全程在您的设备上进行，不会上传到任何第三方的API端点

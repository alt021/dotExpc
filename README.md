一个聚合了你所有快递和出库码的APP

## 主要功能

- 基于Miuix的现代化UI界面
- 高度优化的软件包体积和缓存管理
- 完善的个性化定制
- 一站式取件码管理和导入
- 聚合两大主流驿站系统身份码，快捷展码出库
- 所有页面均来自官方，保证数据安全
